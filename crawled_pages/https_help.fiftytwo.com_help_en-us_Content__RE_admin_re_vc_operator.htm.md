Manage shop assistants  Manage shop assistants in 52ViKING Client  This topic is primarily for administrators and other people who manage a Fiftytwo solution In  you manage shop assistants through the mask VB08 in the Functions menu:  new shop assistant 1. In the 52ViKING Client Functions menu window, expand Maintenance B VB If you don't see the Functions menu which isn't a menu, but a window in 52ViKING Client, select Window  Show views  Others in the menu, expand ViKING, and then select Functions menu. Content in the Functions menu, called masks, reflects the selected server's language, so if your organization operates in a multi-language environment, the masks may be in another language than your 52ViKING Client. In the following, we assume that the server uses English. 2. Double-click Operators VB08 3. In the Cashier number field, specify the shop assistant's number max. six digits, follow your organization's numbering scheme, and then press F5 on your keyboard to create a database record for the new shop assistant 4. Specify the operator's Name 5. Select which Category the new shop assistant should belong to Category 1 is the lowest level, with access to a limited set of features. Category 9 is the highest level, with access to most features. You can't give another user a higher set of user rights than you have yourself. This is to prevent creation of unapproved power users who could threaten system security. 6. Optionally, select further settings, for example Supervisor function, which gives access to using the masks  for monitoring operator actions in connection with transactions on a selected till 7. When ready, press F12 or Esc on your keyboard to save your changes  should initially use the password 000, and then click Change password. They can then specify a password of their own choice.
