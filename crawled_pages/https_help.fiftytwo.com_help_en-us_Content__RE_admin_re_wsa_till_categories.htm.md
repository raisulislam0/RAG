Till categories  Manage till categories in 52ViKING Store Management  This topic is primarily for administrators and other people who manage a Fiftytwo solution You may need to have particular user rights in order to use this functionality. Ask your Fiftytwo administrator if you're in doubt. In 52ViKING, you define tills' allowed feature sets that is which features it's permitted to use on tills by assigning each till to a till category. The category then defines the permissions that individual tills that are assigned to the category will inherit. Depending on your type of organization, you may, for example, want to set up till categories for regular checkout tills, information desk tills, self-service checkout SCO tills, etc. You can also set up  for example shop assistant categories for operators, salespersons, supervisors, store managers, etc. The user rights that you can specify for a shop assistant category are exactly the same as the permissions that you can specify for a till category. If there's a conflict example: a shop assistant is allowed to handle returns, but returns aren't allowed on the till that the shop assistant works at, the most restrictive option will apply in the example, the shop assistant will then not be able to handle returns at the till in question. You don't necessarily need to set up categories for both shop assistants and tills. It depends on your organization's needs. Some organizations only set up one of the two types of categories, for example only categories for shop assistants. Ask your Fiftytwo consultant if you're in doubt.
