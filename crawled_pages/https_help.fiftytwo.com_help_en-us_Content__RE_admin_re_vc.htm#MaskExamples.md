Click  in the top right corner of the dashboard. 2. You configure a general dashboard, but you can still make it server-specific so that it'll only display relevant content when you connect to a server. To do that, make sure that Use server configuration for widgets is selected.  Benefit: The dashboard only displays content that's relevant  Disadvantage: Certain types of widgets can't be displayed note how you can't add widgets to the list of selected widgets, or remove them from the list, while Use server configuration for widgets is selected If you clear the Use server configuration for widgets box, you can add more available widgets to the dashboard, but note that some servers may not have content to display in those widgets. You'll also be able to remove unwanted widgets. 3. Select whether you want your widgets in a Column or Grid layout.  Column: Takes up less space, but may not always look good because widgets aren't aligned and have different sizes  Grid: Takes up more space, but often looks great because widgets are aligned and have standard sizes For both options, you can select a 1-, 2-, or 3-column layout and control the horizontal and vertical space between widgets. 4. When ready, click OK.  individual widgets Once you have widgets on your dashboard, you'll find that you can configure some of the widgets. For example, you can configure the Weekly revenue widget to display either a bar chart of a graph. To configure a widget, click  in the top right corner of the required widget.  types and day-to-day use of dashboard These are the available types of dashboard widgets, and things that are relevant to look out for in day-to-day operation of your 52ViKING system:  System monitor widget: Displays information about the selected server, for example:  Session: A session is a day's transactions on the POS system until the end-of day procedure. For technical reasons, the first day that your organization uses the POS system is session 2, the following day is session 3, and so on.  Status: 52ViKING has five important status categories that run automatically:  29 - Waiting for start of day normally, 52ViKING automatically handles start and end of day, but if required you can start the day manually in the 52ViKING Client Administration menu  30 - Store open and trading  37 - End of day  39 - Waiting for start of night batch post processing  40 - Running night batch  Disk usage: Disk usage shouldn't be above 80. If it gets close to 80, you must free up disk space on the server to make sure it keeps running without problems.  if you need help with this.  Transaction monitor widget: Displays the number of messages exchanged between the server and the tills. The number of sent and received messages should match. If it doesn't, it means that one or more exchanges of data have gone wrong, which could indicate an error.  Tills widget: Displays the number of tills that are signed on, signed off, offline turned on, but without connection to 52ViKING, and turned off. If a till is offline, there may be a connection problem between the till and the 52ViKING store controller. When a til is offline, it doesn't get price updates from the server, and the till's revenue is not added to the store's daily revenue, which is why it's important to get the till online again as soon as possible, and preferably before end of day.To quickly troubleshoot an offline till, you can: 1 Restart the till, 2 Check that the till has a working network connection, 3 Check that all of the till's hardware peripherals receipt printer, etc. are turned on, 4 Check that the receipt roll is inserted correctly. To get a detailed overview of tills and their status in a separate window, click the Show tills link. Details in the separate window include:  Last: Date on which store controller last communicated with the till in question  Telegram: Time of last communication between store controller and the till in question  PLUs: Number of price updates sent to the till In the separate window, you can right-click the line that represents a till to get a menu of configuration and monitoring options for the till in question.  Lines widget: Only relevant if your organization's 52ViKING solution monitors communication lines to and from other devices that tills.  Daily revenue widget: Displays revenue, in real time, from tills that are connected to the 52ViKING store controller. With the mask PA02 you can configure comparison between current revenue and historical revenue from the last week or the last year. For more information about masks, see  in the following.  Weekly revenue widget: Displays turnover from the last seven days as a bar chart or a graph. To view the exact numbers, place your pointer over the bars or the data points in the graph.  Customers per hour widget: Displays the number of customers per hour based on the number of receipts with actual sales. You can configure  the widget to show Revenue per hour instead, in which case the widget's title changes. So if you remember seeing a Revenue per hour widget, and you want to add it to your dashboard, it's actually the Customers per hour widget that you must add.  Server log widget: Displays relevant log messages from the selected 52ViKING server. Click a log entry to open the full log.  Seller ranking widget: Displays sales numbers, in real time, from each seller in the store. It's not a good idea to use this widget for 52ViKING enterprise controllers because it may slow down the dashboard significantly. You can disable it for enterprise controllers by adding the following line to EC.par:guiovb pinstatistics0  Components widget: Displays status of  for example the U component that handles article changes, the u component that handles scheduled changes, or the Z component that handles post processing. To get a detailed overview of components and their status in a separate window, click the Show components link. In the separate window, you can right-click the line that represents a component to stopstart the component's process or view its logs  Externals widget:  Stores widget: Only relevant for 52ViKING enterprise controllers. Displays the number of stores that are online ok, offline, and stores that are waiting for the nightly batch processing. To get a detailed overview of stores and their status in a separate window, click the Show stores link  Tasks widget: Only relevant if your organization's 52ViKING solution is set up to monitor specific system tasks.  Customer counter widget: Only relevant if your organization's 52ViKING solution has an integration to shop door entry sensors.  menu: Query and maintain selected server In 52ViKING Client, the Functions menu contains tools for querying and maintaining the selected server. Each tool is called a mask, and available masks vary from server to server. Also, the masks reflect the selected server's language, so if your organization operates in a multi-language environment, the masks may be in another language than your 52ViKING Client. If you don't see the Functions menu which isn't a menu, but a window in 52ViKING Client, select Window  Show views  Others in the menu, expand ViKING, and then select Functions menu. To use a mask in the Functions menu, double-click the required mask. When you work with masks in 52ViKING Client, and you want to select something in a dropdown list, you select the required object by double-clicking it. Examples of masks:  Terminal monitoring CM: View all operator actions in connection with transactions on a selected till.  Real-time monitoring CM01: View transactions in real time.  Operations analysis CM02: View transactions from a particular session day, with the option of limiting results to a particular receipt number range.  Help programs HE: Useful day-to-day management features.  Release operatorterminal HE08: Operators can get blocked upon too many incorrect login attempts. With this mask you can release a specific operator on a specific till.  Print from spool PR  Print from spool PR00: Get all lists from the selected server from a selected session day, and either display them on the screen or print them.  Queries SP:  Single article, turnover history SP011: Select required article, and view turnover quantity, amount, etc. for each session day. In most organizations, the dropdown list of articles is very long, but you can type parts of the article number or article name in the dropdown list to filter the list and quickly find the article that you want.
