Operator balance search  View operator balances in 52ViKING Store Management  This topic is primarily for administrators and other people who manage a Fiftytwo solution You may need to have particular user rights in order to use this functionality. Ask your Fiftytwo administrator if you're in doubt. On a 52ViKING solution, a session is a day's transactions on the POS system until the end-of day procedure. In  you can search  balances per session to view information about each operator's number of customers, cancellations, returns, zero sales, payment methods, turnover, etc. during the selected session.  for and find operator balances 1. Open 52ViKING Store Management in a browser, connect to the IP address or hostname of the required 52ViKING store controller, and log in. 2. Navigate to operator balances: 1. Expand  the menu in the left part of the page 2. Expand Reports 3. Select Operator balance 3. On the Operator balance page, select the period of time that you want to cover in your search:  Today  Yesterday  Date  Date range For date and date ranges, click the  icon to quickly pick a date or date range. 4. In the Result column, select the required session. 5. In the right part of the page, you can now view the balance of each operator that has worked on the selected session. If multiple operators have worked on the selected session, the report is sorted by operator number. If the report involves multiple operators, it may be long. In that case, use the search field above the report to quickly find the operator name or number, payment methods, amount, or similar that you want to view information about. 6. If required, click the Print button to print the report.
