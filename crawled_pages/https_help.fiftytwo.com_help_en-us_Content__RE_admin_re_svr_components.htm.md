General server components  52ViKING general server components  This topic is primarily for administrators and other people who manage a Fiftytwo solution On  previously also known as 52RETAIL, various server components handle various processes. For example, the U component handles article changes and the Z component handles post processing. It's the composition of components on a 52ViKING server that gives the server it's identity as a store controller, enterprise controller, or omnichannel controller. 52ViKING systems are different. Not all of the following components may be used on your servers.
