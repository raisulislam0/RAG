Peripheral till devices  Manage peripheral till devices in 52ViKING Store Management   This topic is primarily for administrators and other people who manage a Fiftytwo solution You may need to have particular user rights in order to use this functionality. Ask your Fiftytwo administrator if you're in doubt. Peripheral till devices are typically hardware devices like physical payment terminals also known as EFT terminals or receipt printers, but they can also be virtual devices like mobile payment services. The browsers used for till displays are also considered peripheral till devices. If your organization uses a special numbering scheme for peripheral devices, it's important that you follow that scheme. Ask your Fiftytwo administrator if you're in doubt. EFT means Electronic Funds Transfer that's payment terminals and CMS means Cash Management System that's an automated solution for end-to-end cash handling that typically provides features for intake of coins and banknotes and helps you automate cash-handling through to reconciliation.  Text section: Specify the four-character code of the 52ViKING text section that contains the relevant peripheral device configuration parameters, for example BRW for the text section that contains configuration parameters for browsers or EFT for the text section that contains configuration parameters for payment terminals.  It's a text-based configuration of an element in a 52ViKING solution, for example of how a receipt should be structured, how payment terminals should work, or how big browser windows should be. Text sections are typically set up and stored on your 52ViKING store controller by a Fiftytwo consultant when you get your 52ViKING system, so that you can simply refer to them instead if having to write the configurations yourself. Ask your Fiftytwo consultant if you're in doubt about where to find your text sections.  Section: Specify the heading of the text section segment that contains the specific configuration for the required peripheral device type.  A text section with configuration parameters is structured into one or more segments that each represent a particular configuration. For example, the EFT text section with payment terminal configuration parameters will contain a segment for each payment terminal type that your organization uses, for example a segment about Ingenico Lane3000 configuration and a segment about Verifone P400 configuration. So if the peripheral device that you add is a Verifone P400 payment terminal, and the EFT text section has a segment with Verifone P400 configuration parameters that has the heading , specify VerP400 without the angled brackets used in the text section itself. What you specify here concerns general setup of a type of peripheral device, for example a Verifone P400 payment terminal.
